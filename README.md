# Mates de 4rt

Joc educatiu en català de matemàtiques per a 4t de primària.

## Tema actual: fraccions

El joc inclou exercicis de:

- Suma de fraccions
- Resta de fraccions
- Multiplicació de fraccions
- Divisió de fraccions

Les operacions de suma i resta es resolen per passos:

1. Es busca el mínim comú múltiple (mcm) dels denominadors.
2. Es transformen les fraccions perquè tinguin el mateix denominador.
3. Es sumen o resten els numeradors.
4. Es simplifica el resultat, si és possible.

## Dificultat

- **Fàcil:** denominadors petits i resultats senzills.
- **Mitjà:** denominadors més variats i simplificacions.
- **Difícil:** operacions més complexes i més passos.
